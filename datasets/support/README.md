# Synthetic support-policy benchmark

Twelve original, fictional service-policy documents and 27 manually specified
questions. Includes paraphrases, numeric facts, similar retention/expiration
policies, and three questions labeled with multiple relevant documents.

This dataset is released under the repository's MIT license. It contains no
customer data and makes no claims about a real service. It is a reproducible
engineering fixture, not a held-out research benchmark or proof of general
retrieval quality. No model training is performed. Both retrieval and answer
metrics can be inspected question by question.
