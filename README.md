# RAGBench

A Python project for evaluating retrieval configurations in RAG systems.

## Development setup

Requires Python 3.12.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
```

The package foundation is in place. The next steps are validated configuration,
document ingestion, retrieval implementations, and benchmark evaluation.
